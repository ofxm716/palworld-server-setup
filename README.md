3. 打开 PowerShell，执行下面这条命令：

powershell

4. 等屏幕上出现 `PalServer deploy success!`，说明服务端装好了。

## Linux 一键部署和手动 SteamCMD：想自己控制的走这条

Linux 方案适合稍微懂点命令的人。系统选 Ubuntu 最新版，SSH 连上去执行：

bash
wget -O - https://tc2.zeruns.tech/other/pal-server-install.sh | sh


资料里说装完之后服务会自动开机自启，服务器重启不用手动拉进程。这一点比 Windows 方案省心，代价是后面改配置、看日志都要用命令行。

想完全自己掌控的人可以走 SteamCMD 手动安装，通用流程是这样：

1. 装 VC 运行库、DirectX 和 SteamCMD。
2. 在 SteamCMD 目录打开 PowerShell，执行：
   
   steamcmd +login anonymous +app_update 2394010 validate +quit
   
   这里的 `2394010` 是幻兽帕鲁专用服务端的 App ID，别填错。
3. 进入安装目录：`cd .\steamapps\common\PalServer`
4. 启动服务端：`PalServer.exe port=8211`
5. 弹出一个新的命令行窗口，进程名显示 `PalServer-Win64-Test-Cmd.exe`，就是开服成功了。

手动方式的好处是所有文件都在你手里，坏处是每次服务端更新都要自己重跑一遍 SteamCMD。

## 朋友连不上？按这个顺序查

“大概率是端口没开”这句话在帕鲁开服里出现频率最高，但实际排查可以更细一点，按下面顺序走一遍，绝大多数连接问题能定位到。

1. **服务端进程活着吗**。Windows 上看任务管理器里有没有 `PalServer-Win64-Test-Cmd.exe`，没有就说明服务端没起来或者崩了。
2. **NAT 端口映射建了吗**。雨云控制台进 NAT 端口映射，确认有一条把内网 8211 映射出去的规则，协议是 UDP。只建了 TCP 的规则没用。
3. **发的是映射后的地址吗**。要发公网地址加公网端口，不能把内网 IP 发出去。
4. **服务器设了密码吗**。设置过 `ServerPassword` 的话，朋友进服要输密码，输错会表现为连不上。
5. **地址格式对不对**。客户端填的是 `IP:端口`，中间用英文冒号。

云服务器自己还要看一层安全组或者防火墙，游戏云面板做的映射一般已经处理好了，普通云服务器需要你手动放行 UDP 8211。

## 改参数：配置文件复制过去才生效

这是新手最容易白忙一场的地方。默认模板放在：


\steamcmd\steamapps\common\PalServer\DefaultPalWorldSettings.ini


直接改这个模板不会生效。要把模板内容复制到下面这个路径，再改这个副本：


\steamcmd\steamapps\common\PalServer\Pal\Saved\Config\WindowsServer\PalWorldSettings.ini


配置文件里的可调项有四十种左右，新手先动这几个就够：

- `DeathPenalty`：死亡掉落。`None` 不掉落，`Item` 只掉物品，`ItemAndEquipment` 掉物品和装备，`All` 连帕鲁一起掉。和朋友玩想轻松点选 `None`。
- `ExpRate`：经验倍率。想快点升级就调高。
- `PalCaptureRate`：捕捉率。调高会明显降低抓帕鲁的难度。
- `ServerPlayerMaxNum`：服务器最大玩家数，按你的配置和内存来定，别设得比机器扛得住的还高。
- `ServerName` 和 `ServerDescription`：服务器名和描述，方便朋友在列表里认出来。
- `AdminPassword`：管理员密码，设置之后才能在游戏里用管理命令。
- `ServerPassword`：进服密码，只给朋友玩就设一个。

改完保存，重启服务端进程才会读到新配置。

## 长期开着不崩：内存泄漏和老老实实的两个补丁

幻兽帕鲁服务端有内存泄漏的老问题，跑久了内存占用会一路往上走，最后卡顿甚至崩溃。这不是你机器买小了，是游戏本身的行为。两个应对办法：

**配虚拟内存（SWAP）**。8G 内存的机器额外开 8 到 12G 的 SWAP，相当于给内存加一层缓冲垫。Windows 在系统属性里调虚拟内存大小，Linux 用 `fallocate` 创建 swapfile。

**配自动重启脚本**。内存占用超过 90% 就自动重启帕鲁进程，资料里的说法是回档 10 秒左右，玩家基本感觉不到。这比等它崩了再手动拉起来强。

如果不想自己写脚本，可以用 `palworld-server-tool-enhanced` 这类第三方管理面板。它基于存档解析、官方 REST API 和 RCON 做可视化界面，能看玩家、公会、帕鲁和背包数据，支持踢人、封禁、广播、平滑关闭、定时重启、存档备份，还能直接编辑 `PalWorldSettings.ini`（改之前会自动备份，改坏了会回滚）。它的 SteamCMD 更新功能里 App ID 固定是 `2394010`，不接受自定义命令。

用这类面板有一条安全线要守住：游戏 REST API 的 8212 端口、RCON 的 25575 端口、面板自己的进程控制接口，都不要直接暴露到公网。想远程访问就走 Cloudflare Tunnel 这类通道，并且在面板登录之外再加一层身份验证。开私服被扫端口不是什么稀罕事。
